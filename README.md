# 🐲 苏州奶龙大学

> **Soochow Nailong University** · 养天地奶龙,法古今完人

一个纯静态的玩梗小站:打开就是奶龙壁画背景的"苏州奶龙大学"首页,倒计时结束后自动跳转到 [苏州大学官网](https://www.suda.edu.cn/)。

**本站为个人趣味作品,与苏州大学没有任何隶属或合作关系。**

## 打开之后会发生什么

1. 奶龙壁画以电影感的缓慢拉近开场,毛玻璃导航、标题与校训依次淡入;
2. 玻璃卡片里开始 **6 秒倒计时**,细进度条同步收缩;
3. 倒计时归零,自动前往苏州大学官网 `www.suda.edu.cn`;
4. 不想等?点 **「立即前往苏州大学官网」** 直接走;想多看一眼?点 **「取消自动跳转」** 停下来。

切到别的标签页时倒计时会暂停,回来再继续——不会出现"人不在,页面自己跑了"的情况。

## 设计

整体走 **Apple 式深色产品页**的路子,和奶龙壁画形成反差:

- **排版**:标题与校训用 `宋体 / Songti SC / 思源宋体` 衬线字,毛玻璃区域(顶部导航、倒计时卡片)内的数字与按钮用 `SF Pro / 苹方` 无衬线;大标题 `clamp()` 流体缩放,配上浅下深的渐变文字
- **背景**:全屏图 + 上下电影感压暗(纯 CSS 渐变,不改动原图),入场 2.2s 缓动拉近,之后极慢呼吸
- **质感**:`backdrop-filter` 毛玻璃导航与卡片、圆角药丸按钮、`#0071e3` 苹果蓝
- **图标**:奶龙头像做成圆角方形应用图标,同一个图同时用作页面主图标、导航小标和 favicon
- **动效**:入场为「淡入 + 上浮 + 去模糊」,缓动曲线 `cubic-bezier(.16,1,.3,1)`,依次延迟 0.12s 交错

## 特色

- **零依赖**:没有框架、没有构建、没有 CDN、没有外部字体。一个 `index.html` + 一张图,断网双击也能看
- **对国内网络友好**:只用系统自带字体(宋体 / 思源宋体),不请求 Google Fonts,打开不转圈
- **细节到位**:
  - 细进度条与数字实时同步,`aria-live` 播报剩余秒数
  - 尊重系统的「减少动效」设置,开了就不放动画
  - 手机 / 平板 / 桌面自适应,窄屏自动改为居中堆叠布局
  - 键盘可操作,`:focus-visible` 有明显焦点框
  - 404 页面也是同一套深色风格,写着"这只奶龙迷路了",3 秒自动回首页
  - `robots.txt` + `sitemap.xml` + 结构化数据,方便搜索引擎收录

## 技术栈

`HTML` + `CSS` + 原生 `JavaScript`,没有别的了。背景图用一张 PNG,压暗、晕影、毛玻璃全部交给 CSS 处理(不改动原图)。

## 自己改

| 想改什么 | 改哪里 |
| --- | --- |
| 跳转目标网址 | `index.html` 里搜 `www.suda.edu.cn`,共 3 处(`TARGET` 变量、按钮 `href`、页脚链接) |
| 倒计时秒数 | `index.html` 脚本里的 `var TOTAL = 6;` |
| 背景图 | 覆盖 `assets/nailong.png`(建议宽 1600px、1MB 以内) |
| 图标 / favicon | 覆盖 `assets/nailong-icon.png`(512×512)、`assets/apple-touch-icon.png`(180×180)、`assets/favicon.png`(64×64),三张用同一张方图导出即可 |
| 校名 / 校训 / 文案 | `index.html` 的 `<h1>`、`.subtitle`、`.hint` 几行 |
| 配色 | `index.html` `<style>` 顶部的 `:root` 变量(`--bg` `--text` `--blue` `--btn` `--glass` 等) |
| 倒计时文案 / 按钮文字 | `<b id="status">`、「立即前往苏州大学官网」、「取消自动跳转」 |

本地不用起服务器,双击 `index.html` 就能预览。
