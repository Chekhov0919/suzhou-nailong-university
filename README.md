# 🐲 苏州奶龙大学

> **Soochow Nailong University** · 养天地奶龙,法古今完人

一个纯静态的玩梗小站:打开就是奶龙壁画背景的"苏州奶龙大学"首页,倒计时结束后自动跳转到 [苏州大学官网](https://www.suda.edu.cn/)。

**本站为个人趣味作品,与苏州大学没有任何隶属或合作关系。**

![首页预览](assets/nailong.png)

---

## 打开之后会发生什么

1. 全屏奶龙壁画缓缓呼吸式放大,校徽旋转,标题与校训依次浮现;
2. 中央一枚鎏金圆环开始 **6 秒倒计时**;
3. 倒计时归零,自动前往苏州大学官网 `www.suda.edu.cn`;
4. 不想等?点 **「立即前往苏州大学官网 →」** 直接走;想多看一眼?点 **「取消自动跳转」** 停下来。

切到别的标签页时倒计时会暂停,回来再继续——不会出现"人不在,页面自己跑了"的情况。

## 特色

- **一眼玩梗**:米色宣纸质感 + 暗红鎏金配色 + 宋体大字,做成"民国老校门"那一挂的庄重感,和一只奶龙形成强烈反差
- **零依赖**:没有框架、没有构建、没有 CDN、没有外部字体。一个 `index.html` + 一张图,断网双击也能看
- **对国内网络友好**:只用系统自带字体(宋体/苹方/微软雅黑),不请求 Google Fonts,打开不转圈
- **细节到位**:
  - 倒计时圆环 + 数字实时同步,`aria-live` 播报
  - 尊重系统的「减少动效」设置,开了就不放动画
  - 手机 / 平板 / 桌面自适应,标题用 `clamp()` 流体缩放
  - 键盘可操作,`:focus-visible` 有明显焦点框
  - 404 页面是"这只奶龙迷路了",3 秒自动回首页
  - `robots.txt` + `sitemap.xml` + 结构化数据,方便搜索引擎收录

## 技术栈

`HTML` + `CSS` + 原生 `JavaScript`,没有别的了。背景图用一张 PNG,压暗和晕影全部交给 CSS 渐变处理(不改动原图)。

## 自己改

| 想改什么 | 改哪里 |
| --- | --- |
| 跳转目标网址 | `index.html` 里搜 `www.suda.edu.cn`,共 3 处(`TARGET` 变量、按钮 `href`、页脚链接) |
| 倒计时秒数 | `index.html` 脚本里的 `var TOTAL = 6;` |
| 背景图 | 覆盖 `assets/nailong.png`(建议宽 1600px、1MB 以内) |
| 校名 / 校训 / 文案 | `index.html` 的 `<h1>`、`.motto`、`.lede` 几行 |
| 配色 | `index.html` `<style>` 顶部的 `:root` 变量(`--red` `--gold` `--paper` 等) |

本地不用起服务器,双击 `index.html` 就能预览。
